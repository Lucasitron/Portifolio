O que é

Plataforma web que centraliza a gestão operacional de um FabLab / laboratório de fabricação digital: máquinas, membros, projetos, estoque, finanças, produção de encomendas, documentação técnica e rotinas 5S.

Problema que resolve

Organizar a operação do laboratório em um único painel: encomendas saem da calculadora para o kanban de produção, o consumo de materiais baixa o estoque automaticamente, a receita entra no financeiro e o Painel TV exibe a operação em tempo real para todos.

Como funciona

Dashboard admin com KPIs e gráfico de despesas, kanban com 4 etapas (Planejamento → Execução → Aguardando Retirada → Entregue), manutenção com chamados por máquina, estoque com entradas/saídas e um Painel TV com atividades abertas e ranking de gamificação.

Stack
ReactTypeScript ViteTailwind v4 shadcn/uiNode.js ExpressPostgreSQL

Backend planejado com API REST e snapshot inicial via /api/snapshot; dados de demonstração são fictícios.

Como usar o simulador

No modo automático, o ciclo real de operação roda sozinho (~1 s por etapa) — o monitor em operação ganha brilho e LED piscando, e cada evento aparece no terminal de logs. No modo interativo, assuma o papel do operador: crie encomendas, mova cartões no kanban, confirme consumos e chame a próxima atividade no Painel TV (ative o som para ouvir as chamadas). Use Reset para reiniciar o expediente com os dados iniciais.
