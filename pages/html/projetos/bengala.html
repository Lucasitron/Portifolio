Sobre o projeto

A Bengala Inteligente é um projeto de acessibilidade tecnológica para pessoas com deficiência visual. O dispositivo utiliza sensores ultrassônicos acoplados a um ESP32 para detectar obstáculos e comunicar ao usuário via vibração e feedback sonoro, com alcance configurável de até 2 metros.

Desafios e soluções

O maior desafio foi minimizar o consumo de energia para garantir autonomia adequada. A solução incluiu deep-sleep entre leituras e gerenciamento de PWM para os atuadores de vibração. A integração com nuvem foi implementada com MQTT para telemetria remota e atualização de firmware OTA.

Resultados

Protótipo funcional entregue com autonomia de bateria de 8+ horas em uso contínuo. O projeto foi expandido com módulo de geolocalização GPS para rastreamento de emergência por cuidadores.
